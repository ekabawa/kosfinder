# Ide: KosFinder

## 1. Pengguna
- Mahasiswa atau masyarakat yang mencari tempat kos, terutama di sekitar kampus. Pengguna tidak perlu login untuk melihat informasi kos.
- Pemilik kos yang ingin mempublikasikan dan mengelola informasi kosnya. Pemilik harus login.

## 2. Masalah
Informasi kos masih tersebar di berbagai media seperti media sosial, grup WhatsApp, dan informasi dari mulut ke mulut. Pencari kos mengalami kesulitan menemukan dan membandingkan informasi harga serta fasilitas kos. Sementara itu, pemilik kos membutuhkan tempat untuk mempublikasikan dan memperbarui informasi kos miliknya.

## 3. Yang diharapkan bisa dilakukan
Untuk pencari kos:
- Melihat daftar kos.
- Melihat detail informasi kos.
- Mencari kos berdasarkan area.
- Memfilter kos berdasarkan harga.
- Mengakses daftar kos tanpa harus login.

Untuk pemilik kos:
- Melakukan registrasi dan login.
- Menambahkan informasi kos.
- Mengubah informasi kos miliknya sendiri.
- Menghapus informasi kos miliknya sendiri.

## 4. Batasan
- Aplikasi dikembangkan untuk Android menggunakan Flutter.
- Backend menggunakan Supabase.
- Pengelolaan state menggunakan Provider.
- Data kos disimpan di database Supabase.
- Versi pertama TIDAK mencakup pembayaran online, chat, ulasan dan rating, rekomendasi AI, verifikasi identitas pemilik, upload foto, dan peta.
